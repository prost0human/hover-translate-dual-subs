# HoverTranslate Dual Subs

[English](README.md) · [Сборка](BUILD_INSTRUCTIONS.md) · [Участие в разработке](CONTRIBUTING.md) · [Лицензии зависимостей](THIRD_PARTY_NOTICES.md)

Независимый **форк** [HoverTranslate](https://github.com/kozii-d/hover-translate) Дмитрия Козия (MIT) для изучения английского на YouTube. Форк сохраняет перевод при наведении и добавляет русскую строку над английской или вверху видео, словарь с контекстом и экспорт в Anki. Это **не** оригинальное расширение из магазина. Об ошибках форка сообщайте в [issues форка](https://github.com/prost0human/hover-translate-dual-subs/issues), не автору оригинала.

## Возможности и ограничения

- Двойные субтитры по умолчанию **выключены**. После включения выбранный переводчик переводит видимые английские строки на русский; оригинальные субтитры остаются интерактивными. Наведение, Shift-выделение фразы, нажатие, авто-пауза и остальные настройки исходного проекта сохранены.
- Растущие автоматические субтитры переводятся частями с ограничением частоты запросов; пока загружается следующий фрагмент, сохраняется подходящий предыдущий перевод. Повторные результаты кэшируются, устаревшие ответы отменяются или отбрасываются. Русская строка всегда переводится `en → ru`, а язык перевода наведённых слов по-прежнему выбирается в настройках.
- Подсветка **приблизительная**: используется перевод выделения и единственное буквальное либо осторожное морфологическое совпадение в русской строке. При неоднозначности выделяется вся фраза. Это не модель выравнивания: даже совпавшие слова могут не соответствовать смыслу; позиция слов не считается доказательством.
- В существующий локальный словарь добавляются доступные предложение, его перевод, название/ссылка и время видео, заметка. Старые записи читаются, поля можно исправить. Повторная запись не затирает прежнюю заметку или контекст. Ссылки на Cambridge English–Russian, Reverso Context и Multitran открывают поисковые страницы, без скрейпинга.
- Новый интерфейс локализован на английском и русском; в остальных поддерживаемых языках новые строки берутся из английского fallback. Базовый Google-переводчик не требует аккаунта или платного API; для DeepL нужен собственный ключ.

## Установка или обновление из архива

Скачайте **производственный ZIP для Chromium** на странице [релизов форка](https://github.com/prost0human/hover-translate-dual-subs/releases), а не GitHub Source code. Распакуйте архив, откройте `chrome://extensions` (или страницу расширений Edge/Brave), включите режим разработчика, нажмите **«Загрузить распакованное расширение»** и выберите папку, где лежит `manifest.json`.

Для обновления уже установленной распакованной версии сначала экспортируйте резервную копию словаря в JSON. Распакуйте новый ZIP во временную папку, скопируйте его содержимое **в прежнюю папку расширения** с заменой файлов, не меняя её путь; нажмите **«Обновить»** на странице расширений и перезагрузите YouTube. При выборе другой папки браузер может создать новый ID с отдельным хранилищем; автоматического переноса между ID нет.

## Установка из исходников: Chrome / Edge / Brave

Требуются Node.js **24.12.0+**, npm **11.6.2+**, Linux/macOS или WSL (скрипты используют `cp`/`rm`). Выполните в корне репозитория:

```bash
npm ci
npm ci --prefix extension
npm ci --prefix popup
npm run setup:chrome          # для Edge также можно npm run setup:edge
npm run build
```

Откройте `chrome://extensions`, `edge://extensions` или `brave://extensions`, включите режим разработчика, нажмите **«Загрузить распакованное расширение»** и выберите **корень репозитория**, где находится созданный `manifest.json`, а не `extension/dist`. Закрепите расширение и перезагрузите открытые вкладки YouTube. Старую копию можно сохранить, но для проверки отключите её на YouTube, чтобы два расширения не изменяли субтитры одновременно. После пересборки нажмите «Обновить» у расширения.

Из Chrome-манифеста удалён публичный ключ оригинала: у распакованного форка будет **другой ID**. Его хранилище отдельно; при переносе папки или переустановке ID тоже может измениться. Заранее сохраняйте JSON словаря. Для публикации нужен собственный ключ/ID, проверка названия, листинга, сайта, privacy policy и разрешений. Скрипт исходного архива включает только отслеживаемые Git файлы: перед созданием архива исходников добавьте новые файлы в коммит. Наследованный Firefox-манифест также получил отдельный ID во избежание подмены оригинала; **Firefox этим форком не проверялся и не заявлен как поддерживаемый**. Унаследованная публикация сайта оригинала через GitHub Pages отключена для форков до замены сайта.

### Перенос старого словаря

Из-за нового ID автоматического переноса **нет** — ни словаря, ни настроек, кэша или API-ключей. Не удаляйте старую копию до проверки:

1. В **старом** расширении откройте **«Словарь → Экспорт JSON»**, сохраните файл и резервную копию.
2. Установите форк, откройте **«Словарь → Импортировать JSON»**, выберите файл; проверьте число импортированных/пропущенных записей и сами слова.
3. Заново настройте языки и при необходимости ключи. Старый экспорт не содержит примеры и видео, которые раньше не сохранялись.

Принимается исходный формат JSON-массива HoverTranslate и JSON-экспорт форка, до **5 МБ / 10 000 записей** за файл. У каждой записи нужны непустые оригинал и перевод; файл проверяется целиком до одного сериализованного сохранения. Дубликаты по оригиналу, переводу и паре языков пропускаются без перезаписи существующих записей; конфликтующие ID заменяются. Старые даты интерпретируются в местном часовом поясе с точностью до секунды, неизвестный формат заменяется временем импорта. JSON не является полной копией профиля. При обновлении версии с *тем же* ID используется прежний `savedTranslations`, новые поля необязательны.

## Работа на YouTube

1. Включите в плеере **CC** и выберите **английскую** дорожку. Расширение читает видимые узлы субтитров, а не API транскриптов. Проверка языка эвристическая и может принять другую латинскую письменность за английскую — выбирайте дорожку вручную.
2. Откройте настройки расширения, установите **«Перевести на → Русский»** для слов, включите **«Двуязычные субтитры (английский → русский)»** и при желании **«Авто-пауза»**. В поле **«Расположение русского текста»** выберите **«Над английскими субтитрами»** или **«Вверху видеоплеера»**. Показывать русскую строку и перекрёстную подсветку можно независимо; доступны размер, прозрачность, фон и расстояние.
3. Наведите курсор на слово. Для фразы удерживайте **Shift** и ведите по соседним словам (или включите постоянный множественный выбор). Русская строка не перехватывает курсор. При стандартном действии нажатие сохраняет выделение. При уходе курсора возобновляется только видео, которое поставило на паузу само расширение; вручную остановленное не запускается. Повторное нажатие паузы, пока видео уже остановлено расширением, не всегда можно отличить от отсутствия действия.
4. Откройте **«Словарь»**, отредактируйте оригинал, перевод, примеры и заметку, откройте источник или внешние словари. Если русская строка ещё не успела перевестись в момент сохранения, поле примера может быть пустым — заполните его вручную.

Автоматические субтитры переводятся постепенно, а не строго слово в слово: первый фрагмент отправляется вскоре после появления, затем растущая строка обновляется не чаще примерно раза в 0,8 секунды на одно окно субтитров. Из-за скорости сети и переводчика русский текст может запаздывать и менять формулировку; при прокрутке строк прежний перекрывающийся перевод может ненадолго оставаться. Когда английский исчезает или сменяется несвязанной строкой, старый перевод убирается. Не все варианты live и встроенного плеера или будущие изменения DOM YouTube гарантированно работают. Переводчик может ошибаться или ограничивать запросы. Поставщику отправляются **видимые фрагменты и строки**, кроме наведённых слов; постепенный перевод может увеличить число запросов и расход платного API. Отключение двойных субтитров прекращает эти запросы.

## Экспорт в Anki

1. В словаре нажмите **«Экспорт CSV для Anki»**. Порядок шести полей UTF-8 CSV: **English**, **Russian**, **Example**, **Example translation**, **Video URL**, **Note**. Кавычки, запятые и переносы экранируются; перед потенциальной формулой электронной таблицы добавляется апостроф. Обычные JSON/CSV тоже сохранены.
2. В настольной Anki создайте колоду и тип заметки с шестью соответствующими полями, если нужен весь контекст. В **«Файл → Импорт»** выберите CSV, разделитель «запятая», тип заметки и колоду; сопоставьте шесть полей. У стандартного Basic только Front/Back: остальные поля не сохранятся без своего типа заметки.
3. Заголовочные директивы `#separator`, `#html:false`, `#columns` поддерживаются Anki **2.1.54+** и не создают карточку из названий колонок. Проверьте предпросмотр, обработку дубликатов и ссылку на видео. Подробнее: [руководство Anki](https://docs.ankiweb.net/importing/text-files.html). AnkiConnect не требуется и не реализован.

Созданный экспортёром пример импортирован в изолированную коллекцию движком Anki 26.9.3: проверены две записи, шесть полей, кириллица, кавычки, перенос строки и слово с `#`. Графический интерфейс настольной Anki вручную не проверен. Сначала импортируйте несколько записей в тестовую колоду и сохраните резервную копию коллекции. Обычные программы для таблиц могут показать служебные директивы как строки.

## Обязательный ручной сценарий

- [ ] На реальном видео в Chrome/Edge/Brave включите английские CC, русский язык перевода, двойные субтитры и паузу. Проверьте оба положения русского текста, читаемость, кликабельность английского, перемотку, изменение размера, полноэкранный режим и отсутствие дубликатов после смены видео.
- [ ] Найдите или подготовьте субтитр с **«back down»**. Наведите на `back`, удерживая Shift перейдите на `down`, проверьте перевод и приблизительную подсветку, нажмите для сохранения. При уходе курсора играющее видео возобновляется; предварительно остановленное вручную — нет.
- [ ] Повторите для **«look forward to»**. При отсутствии однозначного совпадения должна подсвечиваться вся русская строка. Перезагрузите страницу и убедитесь, что записи сохранились.
- [ ] Отредактируйте обе записи, проверьте контекст, время, ссылку на видео и заметку; откройте три внешних словаря и проверьте поиск фраз.
- [ ] Экспортируйте JSON и Anki CSV, проверьте кириллицу, кавычки и переносы. Импортируйте CSV в тестовую колоду Anki по шести полям и проверьте карточки и видео. Отдельно проверьте перенос старого JSON до удаления исходного расширения.
- [ ] Проверьте быструю перемотку, живые авто-субтитры, сетевую ошибку/лимит переводчика: устаревший перевод не должен появиться над новой строкой, ручная пауза должна сохраняться.

## Приватность

Словарь и кэш хранятся в браузере и не выгружаются автоматически; экспорт запускает пользователь. Форк не добавляет аккаунт, аналитику, скрейпинг или загрузку словаря. Google/Bing/DeepL получают переводимый текст и обычные сетевые метаданные; DeepL-ключ хранится локально. При открытии внешнего словаря выбранная фраза попадает на его сайт. Новых разрешений нет: существующий необязательный доступ Bing/DeepL запрашивается при выборе. Ссылка на опрос оригинала при удалении очищается.

Отдельно production content-bundle проверен в headless Chromium с имитацией Chrome API. Реальные YouTube, графический интерфейс Anki и Firefox-ID необходимо проверить вручную.
